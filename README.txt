# Transforme Uma Infância — T.U.I.

Site estático para a campanha de doação de brinquedos.

## Como usar
1. Abra `index.html` no navegador.
2. O cadastro e o último registro de doação ficam salvos no `localStorage` do navegador.
3. O botão de WhatsApp abre uma conversa com o número do projeto.
4. O botão de e-mail abre o aplicativo de e-mail configurado no computador.

## Importante
Esta versão funciona sem servidor, mas o cadastro NÃO é enviado para um banco de dados central. Para ter cadastro real de vários usuários, painel administrativo e armazenamento online, é necessário conectar um backend (por exemplo, Firebase/Supabase) e configurar regras de privacidade e segurança.
